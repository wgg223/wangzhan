# AI提示词页面模块实施计划

## 目标

仿照 https://luocosai.club/ 为网站新增「AI提示词」模块：

- **前台**：独立深色玻璃拟态全屏页 `/ai-prompts`（左侧分类导航+搜索、思维导图总览、分类卡片网格、标题搜索高亮、一键复制、弹窗查看完整提示词，Markdown 渲染）
- **后台**：图形化 CRUD 管理 板块→分类→提示词 三级数据（`/admin/prompts`）

已确认决策：深色风格独立页（不用前台 layout）；三级数据结构；完整功能（地图+搜索+复制+弹窗）；Markdown 服务端渲染。

## 一、数据库（2 个文件）

### 1. `server/config/db-schema.js` — 在 L691（`idx_ai_knowledge_chunks_doc` 之后）插入三张表

```sql
CREATE TABLE IF NOT EXISTS prompt_sections (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL, icon TEXT DEFAULT '', description TEXT DEFAULT '',
  sort_order INTEGER DEFAULT 0, is_active INTEGER DEFAULT 1,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP, updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
CREATE TABLE IF NOT EXISTS prompt_categories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  section_id INTEGER NOT NULL, name TEXT NOT NULL, description TEXT DEFAULT '',
  sort_order INTEGER DEFAULT 0, is_active INTEGER DEFAULT 1,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP, updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (section_id) REFERENCES prompt_sections(id) ON DELETE CASCADE
);
CREATE INDEX IF NOT EXISTS idx_prompt_categories_section ON prompt_categories(section_id);
CREATE TABLE IF NOT EXISTS prompts (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  category_id INTEGER NOT NULL, title TEXT NOT NULL, content TEXT NOT NULL, excerpt TEXT DEFAULT '',
  sort_order INTEGER DEFAULT 0, is_active INTEGER DEFAULT 1,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP, updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (category_id) REFERENCES prompt_categories(id) ON DELETE CASCADE
);
CREATE INDEX IF NOT EXISTS idx_prompts_category ON prompts(category_id);
```

- 级联删除依赖 database.js 已开启的 `PRAGMA foreign_keys = ON`（双驱动均开启）
- 写操作手动更新 `updated_at=CURRENT_TIMESTAMP`（同 articles.js 惯例）

## 二、后台（4 个文件）

### 3. 新建 `server/routes/admin/prompts.js`（约 300-400 行，仿 articles.js 模式 + image-share.js 多实体分节风格）

全部路由鉴权 `isAuthenticated` + `hasPermission('prompts.manage')`；写操作后 `saveDatabase()` + `logActivity(...)` + `queryCache.deleteByPrefix('ai_prompts:')`（清前台缓存）：

| Method+Path | 功能 |
|---|---|
| GET `/prompts` | 管理总览页（三 Tab + 统计卡） |
| POST `/prompts/sections/save` | 板块新增/更新（id 有则 UPDATE） |
| POST `/prompts/sections/delete/:id` | 删板块（级联） |
| POST `/prompts/categories/save` | 分类新增/更新（含 section_id） |
| POST `/prompts/categories/delete/:id` | 删分类（级联） |
| GET `/prompts/prompts/new` | 新建提示词编辑页 |
| GET `/prompts/prompts/edit/:id` | 编辑提示词（404 校验） |
| POST `/prompts/prompts/save` | 提示词新增/更新（校验 title/category_id/content；excerpt 留空自动生成） |
| POST `/prompts/prompts/delete/:id` | 删提示词 |

要点：数组字段防御（`Array.isArray` 取首元素）；`makeExcerpt(content)` 去 Markdown 符号取前 100 字；列表页 JOIN 统计 `category_count`/`prompt_count`；AJAX 请求返回 `{success}` 否则 redirect。

## 实施顺序（每步可独立验证）

1. 建表 + 权限播种 → 启动无 `[DB迁移]` 报错
2. 后台路由 + 挂载
3. 后台视图 + 菜单 → 三 Tab CRUD 走通
4. 前台数据路由 + app.js layout=false
5. 前台页面/样式/脚本 → 完整交互
6. 前台导航链接
7. lint + 全流程手工验证

## 验证方案

- **静态**：`npm run lint`（`lint:frontend` 因缺 `.eslintrc-frontend.json` 是既有问题，勿用）
- **启动**：`npm run dev` 无异常；`SELECT name FROM sqlite_master WHERE name LIKE 'prompt%'` 确认三表
- **后台**：super_admin 登录 → 侧边栏见「🤖 AI提示词」→ 建 2 板块/每板块 2 分类/若干提示词（含 `<script>` 测试串）→ 编辑/删除/级联删除 → 权限可授予普通用户
- **前台**：未登录访问 `/ai-prompts` → 深色玻璃拟态齐全 → 分类导航/思维导图定位 → 卡片→列表→弹窗 → Markdown 渲染正确且 `<script>` 被剥离 → 复制按钮 toast → 搜索高亮 → 移动端抽屉 → 后台停用后前台不显示（10s 缓存）

## 风险与注意

- 数据嵌入 JSON 方案在提示词上千条时 payload 变大；预留后续改为弹窗时 AJAX 拉取单条
- 后台写操作必须清 `ai_prompts:` 前缀缓存，否则前台最多滞后 10s
- CSRF 当前未在服务端启用但按约定携带 `_csrf`/`X-CSRF-Token`
