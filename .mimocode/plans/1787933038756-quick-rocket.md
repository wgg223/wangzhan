# AI 图片生成模块实施计划

## 目标

为网站新增「AI 图片生成」模块：前台 `/ai-image` 页面（常规站点布局），支持**国内外 14 家主流 API** 统一适配器架构生成图片；提示词可手动输入，也可从**已有 AI 提示词库**（`/ai-prompts`，需 `prompts.view` 权限）弹窗选择；支持高级选项（seed / 图生图参考图 / 风格预设）、自动换服务商重试、下载与分享到图片分享；生成图片**本地保存**；后台可配置 provider/密钥（**保存 Key 后自动获取模型列表**）/每日限额。

## 已确认决策

- **14 家 API**：OpenAI DALL·E 3、Stability AI、硅基流动、智谱 CogView、通义万相 DashScope、文心一格、Pollinations（免 Key）、RunningHub（任务轮询）＋ 新增：**腾讯混元、阶跃星辰 StepFun、MiniMax、Replicate、火山引擎豆包、fal.ai**
- 页面：常规站点布局（`frontend/layout.ejs`），**不要** `layout:false`
- 仅网页端，不做 Flutter App `/api/v1` 接口
- 本地保存 `public/uploads/ai-images/YYYYMM/` + 每用户每日限额（默认 20 次，admin/super_admin 不限）
- 高级选项：种子数 seed、图生图参考图（按 provider 能力开关）、风格预设（前端 prompt 模板）
- 分享：下载按钮 + 分享到图片分享模块（复用 images 表与审核流程）
- 失败自动换服务商重试（后台可开关，默认开）
- 后台填写/保存 API Key 后**自动调用模型列表接口刷新 models**（不支持自动获取的平台保留手动填写）

## 二、服务层（14 家 API 调用格式）

目录 `server/services/image-gen/`：
- `index.js` — 入口：查 provider → `decrypt(api_key_enc)` → 调 adapter → 逐张 `validateMagicBytes`（`server/utils/file-validator.js`）+ ≤15MB → 写盘 `public/uploads/ai-images/YYYYMM/ai-<ts>-<rand>.<ext>`（扩展名由魔数决定，白名单 .jpg/.png/.webp）→ INSERT records → `saveDatabase()`。**自动换服务商重试**：失败且 `ai_image_fallback=1` 时，按 sort_order 依次尝试其他 enabled 的 provider（最多再试 2 家），记录实际 provider。错误归一化 `normalizeError()`：401→"API Key 无效或未配置"、429→"触发限流"、ECONNABORTED→"生成超时"、ECONNREFUSED→"连接失败"
- `utils.js` — 下载/解码/存盘（axios `timeout:90000`、`maxContentLength:20MB`、`responseType:'arraybuffer'`）
- `providers/<key>.js` — 每文件导出统一接口：
  ```js
  module.exports = { key: 'openai',
    async generate(cfg /*{apiKey,baseUrl,model,apiPath}*/, req /*{prompt,negativePrompt,size,n,seed,referenceImage}*/)
    → { images: [{ buffer, mime }] },
    async fetchModels(cfg) /* → string[] | null（null=不支持自动获取）*/ }
  ```

**已有 8 家格式**（设计代理已核实官方文档）：

1. **OpenAI DALL·E 3**：`POST {base}/images/generations` Bearer；Body `{model:'dall-e-3',prompt,n:1,size,quality:'standard',response_format:'b64_json'}` → `data[0].b64_json`。fetchModels：`GET /models` 过滤 image 关键词，空则保留内置。
2. **Stability**（multipart 二进制）：`POST {base}/stable-image/generate/{model}` FormData `{prompt,negative_prompt,aspect_ratio:'1:1',output_format:'png',seed,cfg_scale,steps}`；200 直接图片字节。**img2img**：`POST {base}/stable-image/edit/{model}` FormData `{image,mode:'image-to-image',prompt}`。
3. **SiliconFlow**：`POST {base}/images/generations`；Body `{model,prompt,image_size,batch_size,negative_prompt,seed?}` → `images[].url`（**1 小时过期，立即下载**）。**img2img**：`POST {base}/images/edits` `{model,image(prompt=b64),prompt,image_size}`。fetchModels：`GET /models`。
4. **智谱 CogView**：`POST https://open.bigmodel.cn/api/paas/v4/images/generations` `{model:'cogview-3-flash',prompt,size,quality}` → `data[].url`（30 天）。fetchModels：`GET /api/paas/v4/models`。
5. **DashScope 通义万相**（异步）：① `POST {base}/services/aigc/text2image/image-synthesis` Header `X-DashScope-Async: enable`，Body `{model,input:{prompt,negative_prompt?,image?},parameters:{size:'1024*1024' /*注意 * 号*/,n,seed?}}` → `output.task_id`；② `GET {base}/tasks/{task_id}` 每 3s 轮询 ≤60 次，SUCCEEDED → `output.results[0].url`。
6. **文心一格**（OAuth）：① `POST https://aip.baidubce.com/oauth/2.0/token?grant_type=client_credentials&client_id={AK}&client_secret={SK}` → access_token（内存缓存，过期前 5min 刷新）；② `POST {base}/rpc/2.0/ai_custom/v1/wenxinworkshop/text2image/{model}?access_token=` Body `{prompt,width,height,n,negative_prompt?}` → `data[].b64_image`。Key 填 `AK:SK`。
7. **Pollinations**（GET 免 Key）：`GET {base}/prompt/{encodeURIComponent(prompt)}?width=&height=&model=flux&nologo=true&seed=` 直接返回字节；**限流 1 次/15s** → 串行+重试 1 次。fetchModels：`GET {base}/models`。
8. **RunningHub**（任务轮询，已核实官方文档）：① `POST {base}/{api_path}`（api_base 默认 `https://www.runninghub.cn/openapi/v2`）Bearer，Body `{prompt,...}` → `taskId`；② `POST {base}/query` `{taskId}` 每 2-3s 轮询 ≤120s。输出解析容错 `output/data/outputs/images`（元素 `{url}` 或字符串）。

**新增 6 家格式**（实施时以冒烟脚本为准，关键差异）：

9. **腾讯混元**（OpenAI 兼容）：`POST {base}/images/generations` Bearer；Body `{model:'hunyuan-image',prompt,n,size:'1024x1024',response_format:'url'|'b64_json'}` → `data[].url|b64_json`。fetchModels：`GET /models`。
10. **阶跃星辰 StepFun**（OpenAI 兼容）：`POST {base}/images/generations` Bearer；Body `{model:'step-1x-medium',prompt,n,size,seed?,response_format:'b64_json'}` → `data[].b64_json`。fetchModels：`GET /models`。
11. **MiniMax**（OpenAI 兼容）：`POST {base}/images/generations` Bearer（`Authorization: Bearer <key>`）；Body `{model:'image-01',prompt,n,aspect_ratio:'1:1'|'16:9',response_format:'url'|'b64_json'}` → `data[].url|b64_json`。fetchModels：`GET /models`。
12. **Replicate**（任务型）：① `POST https://api.replicate.com/v1/models/{owner}/{name}/predictions`（api_path 存 `black-forest-labs/flux-schnell`），Body `{input:{prompt,negative_prompt?,seed?,width,height}}` → `{id,status:'starting'}`；② `GET /v1/predictions/{id}` 每 2s 轮询 ≤180s，`succeeded` → `output`（URL 数组）。Bearer token。**img2img**：input 加 `image` 字段（URL 或 data URI）。
13. **火山引擎豆包**（Ark OpenAI 兼容）：`POST {base}/images/generations`（api_base 默认 `https://ark.cn-beijing.volces.com/api/v3`）Bearer；Body `{model:'doubao-seedream-3-0-t2i-250528' 或 ep-xxx 推理接入点, prompt, size, seed?, response_format:'url'|'b64_json'}` → `data[].url|b64_json`。**img2img**：Seedream 支持参考图（模型不同或加 image 字段，冒烟确认）。fetchModels：`GET /api/v3/models`（列推理接入点）。
14. **fal.ai**（任务队列）：① `POST {base}/{app_id}`（api_path 存 `fal-ai/flux/dev`；fal.run 同步 / queue.fal.run 异步），Header `Authorization: Key <key>`，Body `{prompt,image_size?,seed?,num_images?}` → 异步返回 `request_id`；② `GET {base}/{app_id}/requests/{request_id}/status` → `COMPLETED` → `GET {base}/{app_id}/requests/{request_id}` 结果 `images[].url`。**img2img**：app 支持 image 输入（如 flux img2img app）。

**fetchModels 统一规则**：结果过滤图像相关关键词（`image|dall|flux|sd3|sd-|seedream|hunyuan|step-1x|image-01|cogview|glm-image|wanx|imagen|qwen-image`），过滤后为空则保留内置 models；失败返回 null 不阻塞保存，前端提示"自动获取失败，可手动填写"。

**超时关键点（已验证）**：`server/app.js:361 server.timeout=30000` 会掐断长生成 → 生成路由内 `req.setTimeout(120000)`；nginx 该 location `proxy_read_timeout` 提到 180s。

## 五、安全与限额

- 权限：前台 `imagegen.use`；提示词库 `prompts.view`；分享 `image-share.access`；后台 `imagegen.manage`
- provider key 仅服务端 `decrypt`，绝不注入前端；列表接口只返回非敏感字段
- 每日限额按服务器本地日期计数，**成功+失败均计次**防刷；admin/super_admin 不限
- 接口限流：每用户 1 分钟 6 次；参考图上传限流 + 5MB + 魔数校验
- 参数校验：prompt ≤1000、negativePrompt ≤500、n∈[1,4]、size 正则 `^\d{1,4}x\d{1,4}$`、seed 0-4294967295、风格预设白名单
- 文件安全：魔数校验通过才写盘，扩展名白名单 .jpg/.png/.webp，单文件 ≤15MB，`fs.mkdirSync(recursive)`；分享到图片分享时复用 image-share 审核配置与净化逻辑

## 六、实施顺序

1. 建表 + 权限/14 provider 种子 + 默认限额/容灾设置 → 重启验证播种

## 七、验证方案

- **静态**：`npm run lint:server`；启动无报错；`ai_image_providers` 有 14 行、`permissions` 含 imagegen.* 2 权限
- **免 Key 冒烟**：登录有 `imagegen.use` 的用户 → `/ai-image` 选 pollinations 生成 → 检查落盘 + records + 历史
- **各家实测**：`scripts/ai-image-smoke.js`（Key 从 `.env` 读，不提交 git），14 家各打 `{prompt:'a red apple', size:'1024x1024'}`，断言 buffer 魔数为 PNG/JPEG 且 >10KB；验证 img2img（stability/siliconflow/fal/replicate/doubao 传参考图）与 fetchModels（openai/siliconflow/zhipu/pollinations/hunyuan/stepfun/minimax/doubao）
- **功能路径**：无 Key → "API Key 未配置"且记录 failed；fallback=1 时首选失败自动换第 2 家成功；分享到图片分享 → images 表出现记录且状态符合审核配置；无 `prompts.view` 隐藏选择入口；daily_limit=2 第 3 次被拒；无 `imagegen.use` → no-permission
- **权限申请**：`/permissions/apply` 可申请 `imagegen.use`

## 风险与注意

- **超时**：`server.timeout=30000` 与 nginx `proxy_read_timeout` 会掐断长生成 → 生成路由 `req.setTimeout(120000)` + nginx location 提到 180s
- Stability/百度官方文档为 SPA，格式基于成熟知识；新增 6 家格式以冒烟脚本实测为准
- SiliconFlow url 1 小时 / 智谱 30 天 / DashScope task_id 24 小时过期 → 必须服务端立即下载
- RunningHub/Replicate/fal 的 endpoint/app_id/模型路径随模型变化，后台可配置；响应解析多字段容错
- 图生图仅对 `supports_img2img=1` 的 provider 开放，其余隐藏上传框
- `/ai-image` 走默认 layout，**不要**加 `layout:false`
